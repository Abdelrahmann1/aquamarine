# أكوا مارين ووتر سيستمز — الموقع الجديد

إعادة تصميم كاملة لموقع [aquamarine-ws.com](https://aquamarine-ws.com/) كموقع ثابت (static) حديث،
عربي بالكامل واتجاه RTL، بنفس محتوى الموقع الأصلي وأصوله.

---

## تشغيل الموقع محلياً

الموقع ملفات HTML ثابتة — يمكن فتح `index.html` مباشرة، لكن يُفضّل تشغيل خادم محلي
حتى تُحمَّل الخطوط وملفات CSS بشكل صحيح:

```bash
perl serve.pl 8099
```

ثم افتح <http://127.0.0.1:8099/>

للنشر: ارفع محتويات المجلد كما هو إلى أي استضافة ثابتة (Netlify, Vercel, GitHub Pages,
أو أي استضافة Apache/Nginx عادية). لا يحتاج الموقع إلى PHP أو قاعدة بيانات.

## التعديل على المحتوى

كل المحتوى موجود في **`build.pl`** في قسم `DATA` أعلى الملف:

| ما تريد تعديله | المتغيّر في `build.pl` |
|---|---|
| العنوان والتليفونات والإيميل والسوشيال | `%C` |
| الخدمات (الاسم، الوصف، الصورة) | `@SERVICES` |
| المشروعات | `@PROJECTS` |
| سابقة الأعمال | `@WORKS` |
| صور الألبوم وترتيبها | `@GALLERY` |
| قائمة خدمات الشركة الكاملة | `@FULLSERVICES` |
| روابط القائمة العلوية | `@NAV` |

بعد أي تعديل، أعد بناء الموقع:

```bash
perl build.pl
```

يمكنك أيضاً تعديل ملفات `.html` مباشرة — لكن أي إعادة بناء ستستبدلها.

## التصميم

**الاتجاه: "المياه العميقة"** — أرضيات كحلية عميقة بإضاءة سماوية مضيئة، مستوحاة من صور
حمامات السباحة الليلية الخاصة بالشركة.

- **الخطوط:** IBM Plex Sans Arabic للنصوص، و IBM Plex Mono للأرقام والعناوين الفرعية
  الصغيرة (طابع هندسي/تقني يناسب طبيعة عمل الشركة). الخطوط محمّلة محلياً — الموقع يعمل
  بدون إنترنت.
- **اللون:** كحلي عميق `#04121f` / `#061c33` مع سماوي مضيء `#22d3ee`، وأرضيات فاتحة
  `#f2f7fa` للنصوص الطويلة.
- **العناصر المميّزة:** خط الماء المضيء بين الأقسام، إضاءة متحركة تحاكي انكسار الضوء في
  الماء، وأرقام عربية-هندية كبيرة (٠١ ٠٢ ٠٣) كعلامات تحريرية على بطاقات الخدمات.
- الحركة كلها CSS، وتُلغى تلقائياً لمن يفعّل `prefers-reduced-motion`.

## ملاحظات على المحتوى

نُقل محتوى الموقع الأصلي كما هو، مع الفروق التالية:

1. **الخدمات: 10 ← 9.** القائمة الأصلية كانت تكرّر «توريد وتركيب غرف البخار» مرتين
   (`level=38` و `level=44`). تم دمجهما في خدمة واحدة، وصورتا الصفحتين معروضتان معاً
   داخل صفحة الخدمة.
2. **تواريخ المشروعات.** كانت كل المشروعات الستة تحمل تاريخ «26 مايو» (تاريخ النشر، لا
   تاريخ التنفيذ). استُبدل بتصنيف للمشروع (فندق / منتجع / مدرسة / فيلا / صناعي).
3. **أوصاف الخدمات.** الصفحات الأصلية كانت تعرض نفس الفقرة العامة لكل الخدمات. أُضيف لكل
   خدمة وصف قصير مأخوذ حرفياً من قائمة خدمات الشركة في صفحة «من نحن» — مع الإبقاء على
   الفقرة العامة والقائمة الكاملة داخل كل صفحة.
4. **سابقة الأعمال.** كانت صفحة `worksarabic.php` فارغة في الموقع الأصلي، والقائمة
   موجودة داخل صفحة «من نحن». نُقلت إلى صفحة مستقلة (38 عملاً) مع فلترة حسب النوع.
5. **مربع البحث** أُزيل — كان يعتمد على PHP، ولا يعمل في موقع ثابت.

## النماذج (اتصل بنا / اطلب الآن)

الموقع ثابت بلا خادم بريد، لذا تُحوَّل بيانات النموذج إلى **واتساب الشركة**
(`+201006637481`) كرسالة جاهزة — وهي الطريقة التي تستقبل بها الشركة الطلبات فعلياً.
التحقق من الحقول يتم في المتصفح، مع سؤال حسابي بسيط بدل كود التأكيد الثابت الذي كان
مكتوباً في صفحة الموقع القديم.

لتفعيل إرسال بريد حقيقي: أضف `action` و `method` إلى الوسم `<form>` في `build.pl`
واحذف اعتراض `submit` من `assets/js/main.js`.

## متبقٍّ للتحسين

- **حجم الصور.** الأصول الأصلية غير مضغوطة (~12 ميجابايت إجمالاً، بعض الصور 1.4 ميجابايت
  للصورة). لم تتوفر أدوات معالجة صور على هذا الجهاز. يُنصح بتمريرها على
  [Squoosh](https://squoosh.app/) أو `cwebp` وتوليد نسخ WebP بعرض 1600px و800px،
  ثم استخدام `<picture>` — سيقلّل زمن التحميل بشكل كبير خاصة على الموبايل.
- روابط إنستجرام ولينكدإن في الموقع الأصلي عامة (`instagram.com` / `linkedin.com`) وليست
  صفحات الشركة — تحتاج تحديثاً في `%C` داخل `build.pl`.
